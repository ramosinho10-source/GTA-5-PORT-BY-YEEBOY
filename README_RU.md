# GTA 5 PORT — Yeeboy (Android)

Это исходный проект Android-приложения-помощника. Он позволяет выбрать APK, полученный вами из легального и доверенного источника, и передаёт его системному установщику Android.

## Важно
- Это **не порт GTA V** и не сама игра.
- В проект не включены APK игры, игровые ресурсы/OBB, лицензия или материалы Rockstar Games.
- Не скачивайте «GTA 5 Android APK» с неизвестных сайтов: такие файлы часто оказываются поддельными или вредоносными.
- Приложение не обходит лицензирование и не отключает защиту Android.

## Сборка
1. Установите Android Studio (актуальную стабильную версию) и Android SDK Platform 35.
2. Откройте папку `GTA5_PORT_Yeeboy` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK сборки появится в `app/build/outputs/apk/debug/`.

Минимальная версия Android: 6.0 (API 23).
